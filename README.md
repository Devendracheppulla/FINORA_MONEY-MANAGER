# 💰 FINORA — Personal Finance Manager

FINORA is a personal finance management web application designed to help users track their income, expenses, and overall financial activity in one simple dashboard.

## 🚀 Features

* 💵 Add and manage income
* 💸 Add and manage expenses
* 📊 View financial summaries
* 📈 Track spending and transactions
* 🧮 Calculate balance automatically
* 🗂️ Organize financial records
* 🌐 Full-stack web application
* 💾 Backend API for storing and managing financial data

## 🛠️ Technologies Used

## ⚙️ How to Run Locally

### 1. Clone the repository


git clone YOUR_GITHUB_REPOSITORY_URL


### 2. Open the project folder


cd FINORA


### 3. Install the required Python packages


pip install -r requirements.txt


### 4. Start the backend server


python -m uvicorn main:app --reload


The backend will run at:


http://127.0.0.1:8000

## 🎯 Project Goal

The goal of FINORA is to make personal finance tracking simple, accessible, and easy to understand.

Instead of manually maintaining financial records, users can use FINORA to manage their transactions and get a clear overview of their financial activity.
